# skincare-ai

피부 질환 및 타입 맞춤 AI 서비스의 AI 모델 / 추론 서버 저장소입니다.

## 역할
피부 이미지·데이터를 분석해 피부 타입 및 질환을 판별하는 AI 모델 개발과, 이를 서비스에 제공하는 추론 서버 구축을 담당합니다.

## 주요 기능 (예정)
- 피부 타입 / 질환 분류 모델 학습 및 개선
- FastAPI 기반 추론 서버 구축
- 백엔드로부터 진단 요청을 받아 결과 반환

## 기술 스택
- Python

## 실행 환경
AI 추론 서버는 팀원 PC에서 구동할 예정입니다.
