# 스킨케어 프로젝트 개발 문서

**2026-10-15 개정:** 현재 합의된 구성은 **Swift iOS 앱 → Spring Boot → FastAPI → DenseNet121 → Qwen2.5**다.
새 범위·목표와 AI 입출력, 비동기 작업·화면 변경은 [개정 수행계획서](09-revised-project-plan.md)를 기준으로 한다.
아래 v1.0 문서의 React·NestJS 및 피부 지표 4종 회귀 전제는 과거 설계이며 순차 갱신 대상이다.

**프로젝트** 스마트폰 촬영 영상 기반 피부 상태 정량화 및 맞춤 성분 추천 AI 서비스
**팀** 스킨케어 — 조장 김우주 / 박성근, 손승우, 이현승, 정도희
**문서 버전** v1.0 (2026-10-01) · 작성 김우주 · 문서 관리 손승우

이 폴더는 개발 착수 시점의 기준 문서입니다. 9/13에 배포한 「개발명세서 v0.1」을 대체합니다.
문서와 코드가 다르면 **문서를 먼저 고치는 PR**을 올리고, 합의된 뒤 코드를 바꿉니다([협업 규칙 §5](06-collaboration.md#5-명세-변경-절차)).
