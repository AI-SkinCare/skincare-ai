# 실제 정면 사진과 증상 설문 후속 검증

배포 중인 DenseNet121 S2는 이전 프로젝트 평가 자료에 없던 공개 임상 정면 사진 **10장 중 6장(60.0%)**을 맞혔다. 증상 설문이 함께 있는 별도 공개 표본에서는 여드름·주사 탐색 모델의 정답이 **7/11 → 8/11장**으로 늘었다. 이때 주사는 한 장 덜 맞혔다. 두 결과는 표본, 비교 조건, 채점 라벨이 다르다.

## 공개 임상 정면 사진

진단명과 사진의 연결을 원 논문에서 확인했다. 정면 또는 거의 정면에서 양쪽 볼과 코가 보이는 임상 사진만 선정했고 대조 사진, 치료 후 사진, 측면, 병변 단독 확대, 소아 증례를 제외했다. 일부 원 논문 사진은 눈을 가렸다. 여러 사진이 붙은 그림에서는 지정된 정면 패널만 분리했다. 원 논문의 촬영 거리, 노출, 해상도와 가림 처리를 유지했다.

| 원 논문 진단 | S2 정답 | 나머지 예측 |
|---|---:|---|
| 건선 | 4/6 | 아토피 1, 여드름 1 |
| 여드름 | 1/1 | — |
| 주사 | 1/3 | 아토피 1, 건선 1 |
| 합계 | **6/10** | **4건** |

서비스 가중치와 전처리를 그대로 사용했다. 모델에 사진 바이트만 전달했고 진단명은 채점에 사용했다. 최대 점수 0.60 미만인 5장도 최고 점수 라벨로 채점에 포함했다.

| 출처 | 사용한 사진 |
|---|---|
| [여드름 증례](https://pmc.ncbi.nlm.nih.gov/articles/PMC6994586/) | Figure 1B |
| [만성 판상 건선 증례](https://pmc.ncbi.nlm.nih.gov/articles/PMC12906923/) | Figure 1의 초기 정면 패널 |
| [안면 건선 증례](https://pmc.ncbi.nlm.nih.gov/articles/PMC7777451/) | Figure 1A의 초기 정면 패널 |
| [안면 건선 증례군](https://pmc.ncbi.nlm.nih.gov/articles/PMC11139169/) | Figures 1–4의 A 패널 |
| [주사 임상 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10412051/) | Figures 1, 2와 5B |

기존 로컬 영상 연구 자료·평가 기록에서 이 5편의 사진을 사용한 기록을 발견하지 못했다. 전체 S2 학습 ID가 없어 학습 전 기간에 걸친 동일 환자·사진 중복 여부는 확인할 수 없다. 같은 논문의 여러 사진을 포함하므로 모집단 정확도나 독립 환자 10명의 성능으로 해석하기 어렵다. 아토피·지루·정상은 이번 정면 표본에 포함되지 않았다. 10장에 대해 앱의 자동 얼굴 검사를 함께 평가하지 않았다. 따라서 표는 사진이 모델까지 전달됐을 때의 결과다.

## 같은 사례의 사진 단독과 사진·증상 비교

SCIN에서 진단 후보의 가중치가 0.65 이상이고 그 진단에 대한 피부과 의사 신뢰도 4/5 이상이 한 번 이상 있는 머리·목 사례는 31건이었다. 부위 검토 후 머리·목만 보고한 사람의 얼굴 부위 사진 중 11건을 골랐다. 1명당 사진 한 장이며 일부는 얼굴 일부만 보이거나 비스듬한 각도, 눈 가림이 있다. 따라서 이 비교는 **여드름과 주사 두 클래스의 얼굴 부위 탐색 결과**다. [SCIN 연구와 라벨 수집 방법](https://doi.org/10.1001/jamanetworkopen.2024.46615) · [데이터 스키마와 이용 조건](https://github.com/google-research-datasets/scin)

동결한 S2의 전체 6개 클래스 로그 확률을 공통 입력으로 사용했다. 두 군 모두 같은 표준화와 L2 로지스틱 회귀를 사용했다. 비교군에는 가려움 언급, 거칠거나 벗겨지는 피부 언급, 기간 범주를 추가했다. 응답이 비어 있으면 증상 빈도나 피부 상태를 추정하지 않았다. 이 자료에서 반복 붉은기, 면포, 앱의 세부 부위, 각질 종류와 가려움 빈도는 같은 방식으로 측정되지 않았다. 양쪽 군에서 같은 사례 하나를 매번 평가용으로 빼고, 나머지 10건으로 표준화와 회귀를 각각 학습했다.

| 정답 | 사진 점수만 | 사진 점수 + 증상 | 차이 |
|---|---:|---:|---:|
| 여드름 | 3/6 | 5/6 | +2장 |
| 주사 | 4/5 | 3/5 | −1장 |
| 합계 | **7/11 (63.6%)** | **8/11 (72.7%)** | **+1장** |

오답이 정답으로 바뀐 사례는 3건, 정답이 오답으로 바뀐 사례는 2건이다. 작은 두 클래스 표본이며 라벨을 만든 피부과 의사에게도 자가 보고 증상이 제공됐다. 이 점수는 공개 라벨과의 일치율이다. 독립적으로 확정한 진단과 정면 촬영·앱 설문이 모두 짝지어진 외부 검증은 남아 있다. 이 실험의 분류기는 서비스에 적용하지 않았다.

## Android 연동 시연

Android 15 에뮬레이터에서 가상 인물 사진과 임시 테스트 계정으로 촬영 화면에서 분석 이력까지 진행했다. 실제 Spring → FastAPI 연결에서 분류 최고 라벨은 정상, 화면에 표시된 모델 점수는 41%였다. 추천은 불확실 상태로 보류됐다. 시연 검사에서 입력한 가려움 응답이 해당 분석에 저장됐음을 확인했다. [26초 시연 영상](https://github.com/AI-SkinCare/skincare-frontend/blob/17080db/Android/docs/analysis-demo.mp4) · [Android PR](https://github.com/AI-SkinCare/skincare-frontend/pull/2)

실제 Spring API에도 같은 가상 사진을 증상 여섯 항목 없이 한 번, 포함해서 한 번 제출했다. 분석 이력에 저장된 설문은 달랐고 최고 라벨, 점수, 불확실 플래그, 전체 확률, 모델 버전은 두 응답에서 같았다. 현재 앱에서 증상 응답이 저장되는 동작과 위 탐색 분류기의 성능 비교는 각각 이 시험과 SCIN 실험으로 확인했다.

## 재현

AI 저장소의 Python 환경에 scikit-learn 1.6.1을 추가하고 기존 S2 가중치를 사용한다. 재현 스크립트는 원본 사진을 제공 기관 서버에서 로컬 경로로 가져온다. 집계 결과만 리뷰에 공유한다. [SCIN Data Use License](https://github.com/google-research-datasets/scin/blob/main/LICENSE)

```powershell
python scripts/prepare_frontal_symptoms.py --out ../verification/frontal-symptoms
python scripts/evaluate_frontal_symptoms.py --inputs ../verification/frontal-symptoms --weights model/weights/densenet121_s2.pt --out ../verification/frontal-symptoms/aggregate.json
```
