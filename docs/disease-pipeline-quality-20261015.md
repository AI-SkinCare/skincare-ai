# 질환 분류 → Qwen2.5 실제 PC 품질 점검

## 판정과 수동 내용 검토

실제 두 모델의 HTTP 연동과 추천 생성은 동작한다. 그러나 비얼굴 입력의 높은 점수 판정과 질환 관리 제약 미준수가 확인돼 현재 상태의 사용자 대상 자동 질환 추천은 보완 후 재시험이 필요하다. 임상 정확도/효능 정확도를 입증한 시험이 아니다.

HTTP 상태가 예상과 같다는 수치는 수송/검증 동작만 의미하며, 내용 품질 통과율이 아니다.

### 우선 보완: 비얼굴 입력 차단

비얼굴 대조군 6개 중 흰색·회색·피부색 단색·무작위 잡음 4개가 uncertain=false였다. 무작위 잡음은 건선으로 분류됐다. 피부색 단색 이미지에 건조 고민을 넣은 전체 API도 HTTP 200과 성분 추천을 반환했다. 0.6 점수 임계값만으로 비얼굴 입력이 차단되지 않았다.

조치: 얼굴 검출·이미지 품질 확인을 분류 앞에 추가하고, 학습 분포 밖 입력 거부를 실제 양성/음성 이미지로 검증한다. 단색 몇 종류를 예외 처리하는 것만으로 해결됐다고 판단하지 않는다.

### 우선 보완: 입력 관리 제약을 따르지 않는 답변

psoriasis_older_oily: 건선·65세·지성 입력의 care_note에는 '각질을 문지르거나 벗기는 관리는 제안하지 마세요'라고 지정했다. 실제 routine은 '주 1~2회 정도는 순한 각질 제거제를 사용하여 묵은 각질을 부드럽게 제거'하라고 권했다. 기존 표현 필터는 이 문장을 제거하지 않았다. atopic_conflicting_scrub_request에서도 강한 물리적 마찰을 피하라는 주의와 함께 PHA/효소 각질 제거를 추가 권유했다. 후자는 의학적 적합성에 대한 전문가 검토가 필요하며 여기서 임상 오답으로 채점하지 않았다.

조치: 질환별 검토된 관리 제약과 근거를 입력/출력 정책에 연결하고 위반 시 추천을 보류한다. 프롬프트와 효능 단정 표현 필터만으로 관리 내용의 적합성을 보증하지 않는다.

### 질환별 차별화 부족

같은 기본 설문에서 건선·아토피·주사·지루의 상위 성분 묶음이 모두 쑥잎 추출물, 대나무추출물, 대나무 잎 추출물, 밤부사 불가리스 싹 추출물이었다. 정상+건조함 사례에도 같은 4개가 나왔다. 현재 매핑과 기존 피부 고민 데이터의 패턴을 반영한 결과이며 질환별 치료/효능 정답으로 학습된 결과가 아니다.

조치: 질환별 전문가 검토를 거친 성분·회피 조건·관리 근거를 준비하고, 기존 고민별 추천과 질환별 보조 관리 성능을 구분해 평가한다.

### 사용자에게 보여주는 성분 효능 설명의 누락/파손

분류 라벨 fixture 10건의 성분 항목은 총 35개이며 purpose가 빈 항목은 11개였다. 추가로 3개는 '및 대나무 잎 추출물', 다른 성분명을 추천하는 문장, '을 추천합니다' 같은 설명 조각이었다. 답변/관리법 전체가 빈 사례는 없었다.

조치: 자유 서술에서 조사와 주어를 잘라 효능을 추출하는 처리를 보완하거나 검증 가능한 구조화 성분 출력을 사용한다. 성분별 설명이 없거나 다른 성분을 가리키는 항목은 표시 전에 걸러낸다.

### 입력에 없는 위치/원인 설명

atopic_basic은 병변 위치를 주지 않았는데 '볼 부위 트러블'을 사용자 문제처럼 서술했다. normal_reported_dry와 psoriasis_older_oily 등에도 입력에 없는 볼/입 주변 표현이 있었다. 여러 답변은 피부 장벽 약화나 수분 부족을 주원인으로 단정했다. 실제 원인이나 병변 위치를 판정한 모델 출력이 입력에 들어간 것은 아니다.

조치: 관찰/설문으로 확인한 사실과 일반적인 가능성 설명을 분리하고, 위치나 원인을 추정할 근거가 없으면 단정하지 않도록 평가 데이터를 보완한다.

- 실제 localhost HTTP 서버, DenseNet121 CPU + Qwen2.5-7B v2 4-bit GPU.
- 질환별 추천 입력은 시험용 라벨 fixture다. 실제 환자 분류 결과가 아니다.
- 얼굴 아닌 이미지는 의도적으로 만든 음성 대조군이다.
- 임상 판별 정확도·질환별 성분 효능 정확도는 측정하지 않았다.
- [원본 GitHub 이슈 #3](https://github.com/AI-SkinCare/skincare-ai/issues/3)에 학습/test 이미지를 커밋하지 않았다고 명시돼 있다.

## 수치와 범위

2026-10-15, 실제 localhost HTTP 서버와 DenseNet121 CPU / Qwen2.5-7B v2 4-bit GPU로 점검했다.

이 26건은 당시 PC 작업 트리에서 측정한 기록이다. 별도 진행 중이던 성분 추출·표현 완화 실험도 해당 환경에 있었으며,
팀 공유 커밋에는 그 별도 실험을 포함하지 않는다. 따라서 세부 내용·설명 누락 수치는 당시 조건의 관찰값이고,
다른 코드·사전·설정 조합의 재현 결과로 단정하지 않는다. 공개 fixture는 그때 기록한 응답을 보존한다.

공유 대상으로 스테이징한 파일만 별도 폴더에 추출한 최종 확인에서는 테스트 114건이 통과했다.
같은 코드에 기존 v2 어댑터·사전을 지정한 실제 모델 연결 점검도 HTTP 200, 성분 4개,
규칙 폴백 없음, Qwen 처리 42.35초로 완료됐다. 이 점검은 프로세스 내부 TestClient와 인공 단색 이미지를 사용했다.
실제 환자 사진이나 임상 정확도를 검증한 것은 아니다.

| 항목 | 관찰 결과 |
|---|---|
| API·검증 동작 | 26/26건 예상 HTTP 상태와 일치 |
| 시험용 분류 JSON에 대한 실제 Qwen 생성 | 10/10건 응답, 규칙 폴백 0건 |
| 추천 생성 시간 | 중앙값 43.33초, 최대 50.04초 |
| 전체 GPU 메모리 최고 관찰값 | 10,501MiB (다른 프로그램 사용분 포함) |
| 비얼굴 음성 대조군 | 6건 중 4건이 높은 점수로 수락됨 |
| 성분 항목 구조화 | 35개 중 purpose 누락 11개, 설명 파손 3개 |

실제 환자 사진과 정답 라벨을 대조한 시험은 수행하지 않았다. 위 수치는 질환 판별 정확도나 성분 효능 정확도가 아니다.
원본 분류 브랜치가 보고한 test ACC 94.91%도 이 통합 파이프라인에서 재측정한 값이 아니다.

대표 JSON은 [계약 fixture](fixtures/disease-pipeline/README.md)에 공개한다. `generated` 응답은 시험용 분류 JSON으로 실제 Qwen이 만든 출력이며 내용상 한계를 그대로 포함한다.
전체 응답 원문·GPU 로그는 로컬 `outputs/disease_quality_20261015/`에 보존하고 원본 학습 데이터나 환자 사진은 공개하지 않는다.
